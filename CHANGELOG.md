## [0.1.0] - 2026-09-02

### Added

- Authentication with a Client Portal account or API key.
- Token-aware model listing and model help.
- Balance and usage inspection.
- Image generation and editing.
- Asynchronous video generation.
- Job inspection, waiting, cancellation, and a local recovery journal.
- Machine-readable output and safe media downloads.
