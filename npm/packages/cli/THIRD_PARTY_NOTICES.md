# Third-party notices

`@api429/cli` is a JavaScript launcher distributed under the API429 MIT
license. It does not embed the native Python runtime itself.

At installation, npm selects one optional `@api429/cli-*` platform package.
That platform package contains the standalone executable together with the
complete `THIRD_PARTY_NOTICES.md` and `licenses/` corpus for its embedded
third-party components.
